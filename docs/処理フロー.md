# ModelTimeTable 処理フロー

## 概要
ModelTimeTableは、大学の時間割を管理・表示するFlaskベースのWebアプリケーションです。セメスタとメジャー（専攻）を選択することで、個別の時間割を生成し、科目の重複チェックや単位計算を行います。

---

## 1. アプリケーション起動フロー

### 1.1 エントリーポイント ([app.py](app.py))
```
app.py
  ↓
src/__init__.py からFlaskアプリケーションをインポート
  ↓
ホスト 0.0.0.0、ポート 8080 でサーバー起動
```

### 1.2 アプリケーション初期化 ([src/\_\_init\_\_.py](src/__init__.py))
```
Flask アプリケーション作成
  ↓
設定ファイル (src.config) を読み込み
  ↓
SQLAlchemy データベース初期化
  ↓
Flask-Migrate マイグレーション設定
  ↓
データベースURI設定: sqlite:///src/modeltimetable.db
  ↓
views と models モジュールをインポート
```

## 2. データベース構造

### 2.1 マスタテーブル ([src/models.py](src/models.py))
- **DayMaster**: 曜日マスタ（月〜金）
- **MajorMaster**: メジャー（専攻）マスタ
- **CourseCategoryMaster**: 履修区分マスタ（必修、選択など）
- **OfferingCategoryMaster**: 開講区分マスタ（前期、後期、1Q〜4Qなど）
- **ClassFormatMaster**: 授業形態マスタ
- **CourseTypeMaster**: 授業種別マスタ
- **ClassroomMaster**: 教室マスタ
- **InstructorMaster**: 教員マスタ

### 2.2 メインテーブル ([src/models.py](src/models.py))
- **TimetableModel**: 時間割モデル（セメスタ、第一・第二メジャーの組み合わせ）
- **Course**: 科目情報（科目コード、科目名、単位数、シラバスURL等）
- **CourseSchedule**: 開講曜限（曜日・時限の情報）
- **GradeYear**: 学年情報

### 2.3 中間テーブル ([src/models.py](src/models.py))
- **TimetableSubject**: 時間割と科目の紐付け
- **CourseClassroom**: 科目と教室の紐付け
- **CourseInstructor**: 科目と教員の紐付け
- **AffiliatedMajor**: 科目とメジャーの紐付け（履修区分含む）

## 3. メイン処理フロー

### 3.1 ホーム画面 (/)

**GETリクエスト:**
```
ブラウザで / にアクセス
  ↓
index() 関数が実行
  ↓
データベースからメジャー一覧を取得
  （「その他」と「情報応用科目」を除外）
  ↓
index.html テンプレートをレンダリング
  ↓
ユーザーにセメスタ、第一メジャー、第二メジャーの選択フォームを表示
```

**POSTリクエスト:**
```
ユーザーがフォームを送信
  ↓
semester, major1_id, major2_id を取得
  ↓
/result ページにリダイレクト（クエリパラメータ付き）
```

---

### 3.2 時間割表示画面 (/result)

**処理の流れ:**

#### ステップ1: パラメータ取得
```
クエリパラメータから以下を取得:
  - semester: セメスタID (1〜8)
  - major1_id: 第一メジャーID
  - major2_id: 第二メジャーID
  - excluded: 除外する科目コード（カンマ区切り）
  - lang: 言語設定 (ja/en)
```

#### ステップ2: 時間割構築
```
build_timetable_result() 関数を呼び出し
  ↓
get_courses_by_semester_and_major() で各メジャーの科目を取得
  - 第一メジャーの科目
  - 第二メジャーの科目
  - その他メジャーの科目
  - 情報応用科目
  ↓
全科目を統合（重複排除）
  ↓
除外科目をフィルタリング
  ↓
build_timetable_from_courses() で時間割データ構築
```

#### ステップ3: 科目の分類とデータ構築
```
各科目について:
  ↓
スケジュール情報を確認
  ↓
【スケジュールがある場合】
  曜日(1〜5: 月〜金)と時限(1〜6)ごとに分類
  ↓
  timetable[曜日][時限]に科目情報を追加:
    - 科目コード
    - 科目名
    - 担当教員
    - メジャータイプ（major1/major2/shared/others/info_app）
    - 開講区分ID
    - 単位数
    - 教室名
    - シラバスURL
    - 履修区分ID
  ↓
【スケジュールがない/通常時限外の場合】
  intensive_courses（集中講義等）リストに追加
```

#### ステップ4: 共有科目の検出
```
第一メジャーと第二メジャーの両方に含まれる科目を検出
  ↓
該当科目の major_type を 'shared' に変更
  ↓
履修区分IDを第一メジャー基準に更新
```

#### ステップ5: 単位計算
```
各メジャーカテゴリごとに単位を計算:
  ↓
calculate_credits() 関数を使用
  ↓
科目の affiliated_majors から履修区分を取得
  ↓
履修区分に応じて必修/選択単位を集計:
  - 必修 (REQUIRED)
  - 必履修 (MANDATORY)
  - 選択 (ELECTIVE)
  - 選択必修 (REQUIRED_ELECTIVE)
  ↓
合計単位数を計算
```

#### ステップ6: 重複チェック
```
detect_and_resolve_conflicts() 関数を実行
  ↓
各曜日・時限を走査
  ↓
2つ以上の科目がある場合:
  ↓
  クォーターの重複をチェック
  （例: 1Qと2Q = 重複なし、1Qと前期 = 重複あり）
  ↓
  重複する科目ペアを記録
  ↓
conflicts リストに追加
```

#### ステップ7: 分岐処理
```
【重複がある場合】
  ↓
choose.html をレンダリング
  ↓
ユーザーに優先する科目の選択を求める
```

```
【重複がない場合】
  ↓
result.html をレンダリング
  ↓
時間割表、集中講義、単位情報を表示
```

---

### 3.3 優先科目選択画面 (/choose)

**処理の流れ:**
```
POSTリクエストでフォームデータを受信
  ↓
semester, major1_id, major2_id を取得
  ↓
一時的に時間割を再構築（除外なし）
  ↓
重複を再検出
  ↓
ユーザーが選択した優先科目を取得
  ↓
選択されなかった科目を excluded_courses に追加
  ↓
excluded をカンマ区切り文字列に変換
  ↓
/result にリダイレクト（excluded パラメータ付き）
  ↓
重複が解消された時間割を表示
```

## 4. 科目検索ロジック

### 4.1 get_courses_by_semester_and_major()

**処理の流れ:**
```
セメスタとメジャーIDを受け取る
  ↓
【メジャーIDが指定されている場合】
  AffiliatedMajor テーブルから該当科目コードを取得
  ↓
  Course テーブルから科目を絞り込み
  ↓
【メジャーID未指定の場合】
  全科目を取得
  ↓
各科目について:
  ↓
  学年の最小値を取得（例: 2年生、3年生）
  ↓
  開講区分IDを取得（1Q、前期、通年など）
  ↓
  calculate_semester() でセメスタを計算
  ↓
  指定されたセメスタに該当する科目のみを抽出
  ↓
該当科目のリストを返す
```

### 4.2 セメスタ計算ロジック

**計算式:**
```
基準値 = (学年 - 1) × 2

【通年】
  前期セメスタ: 基準値 + 1
  後期セメスタ: 基準値 + 2

【1Q、2Q、前期】
  奇数セメスタ: 基準値 + 1

【3Q、4Q、後期】
  偶数セメスタ: 基準値 + 2
```

**例:**
- 2年生の前期科目 → セメスタ3 (基準値2 + 1)
- 3年生の後期科目 → セメスタ6 (基準値4 + 2)
- 4年生の通年科目 → セメスタ7と8 (基準値6 + 1, 6 + 2)

## 9. まとめ

ModelTimeTableは以下の順序で処理を実行します:

1. **アプリケーション起動**: Flask初期化、DB接続
2. **ホーム画面表示**: メジャーとセメスタの選択
3. **科目検索**: セメスタとメジャーに基づいて科目を取得
4. **時間割構築**: 曜日・時限ごとに科目を整理
5. **共有科目検出**: 両メジャーに含まれる科目を特定
6. **単位計算**: 必修・選択単位を集計
7. **重複チェック**: 同時履修不可の科目を検出
8. **結果表示/選択**: 重複がなければ表示、あれば選択画面へ

このフローにより、ユーザーは自分のメジャーとセメスタに合わせた最適な時間割を生成できます。
